# 原生壁纸管理器

一个轻量 Python Windows 程序：导入或下载你已获授权的静态图片，用 Windows 原生 `SystemParametersInfoW` 设置桌面壁纸。

它不会创建桌面覆盖层、隐藏图标、接管右键菜单或播放动态壁纸。

## 功能

- 导入 BMP/JPG/JPEG/PNG，复制到本地资料库
- 所有壁纸入口共用独立 Windows 适配层：设置时同时更新用户配置并广播系统变更，再通过 `SPI_GETDESKWALLPAPER` 有界轮询确认，不再用可能滞后的注册表单次读取误判失败
- “下载并设为壁纸”先把验证合格的图片提交为稳定本地资产，再调用 Windows；即使系统拒绝或暂未确认，也不会删除已下载资源
- 本地页与资源页共用同一应用事务和按钮收尾机制；成功、失败、待确认、持久化异常和 UI 回调异常都会回到可操作状态
- 本地资料库按完整 SHA-256 内容去重：启动时自动合并历史重复记录并保留收藏/最近应用状态，重复下载或应用不再新增副本；哈希经文件大小和修改时间校验后缓存，不阻塞后续启动
- 图库式资源卡片、缩略图和大图预览；点选卡片即可查看与应用
- 元气桌面式双层导航、大图三列网格和固定底部操作栏；静态资源分类直接读取 `cate_nav_v2`，按元气服务端返回的顺序显示，不在本地猜分类 ID
- 资源接入页提供“静态壁纸 / 动态转静态”切换；动态页按元气当前的“关注、精选、最新 + `live/cate_nav_v2` 服务端分类”排列
- “电脑主题”使用独立资源模式，按元气当前服务端配置显示“精选、风景、动漫、科幻、游戏、星空、古风、文艺、简约、随时间变化、美女、动物、明星”，精选合并主题轮播与游标推荐流，分类分页沿用官方筛选条件
- 动态精选把官方推荐流前 5 个资源显示为“今日热榜”：当前作品标题叠放左上角，固定黑色底栏完整显示“今日热榜”、1–5 和转换动作；每 5 秒自动轮播，可点 1–5 或左右箭头切换。电脑主题精选使用独立热门主题接口显示中间主图与两侧预览，可点两侧或左右箭头切换
- 电脑主题降级为 Windows 原生静态主题：先按动态壁纸同款路径把正式画面还原并验证为标准视频，从全片 5 个时间点按原始分辨率择优生成 JPEG，再生成仅含该壁纸的标准 `.theme`。普通主题可安全回退 `preview_video`；明确带时间/天气组件且只有 CWP3/资源包的主题禁止预览回退，避免把固定假时钟应用到桌面。声音、动画、实时组件、鼠标特效、任务栏和窗口皮肤均不注入系统
- 元气动态资源优先转换可验证的干净高清源视频，没有兼容源时回退标准 `preview_video`；两条路径都避开首帧，从全片 5 个时间点解码原始分辨率画面，以清晰度、对比度和曝光质量择优生成 JPEG，再走现有 Windows 原生静态壁纸接口
- 元气 `scene` 预览可能已把时间、天气等场景组件合成进视频；详情页会标记风险，下载或应用前默认取消式二次确认，避免把不会更新的“假时钟”无提示地设为壁纸
- 动态转换结果按实际转换视频地址哈希持久缓存；缓存 JPEG 和元数据每次读取都会重新校验，命中时不再下载视频或启动 FFmpeg
- 联网页卡片先立即显示占位图，再由固定 3 个后台线程下载、解码中/小预览并复用线程内 HTTP 连接；每张完成后单独显示，翻页时取消尚未开始的旧页任务，不阻塞 Tk 主界面。轮播与详情使用较大预览图，只有实际转换/应用才下载并解析正式高清视频
- 顶栏全局搜索从任何主分区（包括电脑主题）进入统一结果页；同时合并本地图库、元气静态搜索和元气动态/主题搜索，不继承当前分类筛选
- 同步元气桌面官网首页公开展示的 5 张精选图片（不需要登录）。每张卡片都标为“元气官网首页公开展示”，可在官网页面和 `app/native_wallpaper.py` 中核对原始 HTTPS 地址
- “官方资源”页直达元气自有完整壁纸站的静态、4K、风景、小清新、动漫、明星、美女、科幻、动物、游戏、体育、汽车等真实分类
- “资源接入”页明确显示正式授权状态；官网网页套壳不能下载、收藏或原生应用，因此不再冒充客户端资源接入
- 真实微信扫码登录：内嵌官方公开登录页 `newvip.ijinshan.com/#/auth/3`，由你本人用微信扫码，客户端读取内存会话并经资源服务 `POST /v1/user/info` 校验（`ret==0` 才判定登录成功）；登录后可“联网浏览壁纸”访问公开壁纸资源
- 复刻官方 PC 宿主可公开验证的登录桥契约与状态机：原生登录回调后必须重新取得用户/设备信息并完成服务端校验
- 收藏、过滤、应用与移出资料库
- 一键扫描本机已有的元气静态壁纸缓存：验证图片、按内容去重并复制到本程序目录；复制后不依赖官方客户端
- 本地图库按每页 12 张分页，避免大量缩略图一次性加载导致窗口卡顿
- 仅接受 HTTPS 静态图片直链的下载入口
- 打开元气官方完整壁纸站浏览真实分类；会员登录与高清原图下载仍由官方客户端完成
- 收藏壁纸按分钟自动轮换
- 生成 Windows 标准 `.theme` 文件，交给系统原生主题与图片幻灯片机制应用
- 提供 Windows 原生鼠标、颜色、声音、通知和锁屏设置入口；不注入桌面或任务栏

## 运行与安装

- **安装版（推荐）**：从 GitHub Releases 下载 `DesktopGallery-<版本>-Setup.exe`。无需安装 Python，默认在当前用户目录安装，并创建桌面和开始菜单启动图标。
- **后续更新**：安装版启动后自动检查 GitHub Releases，也可在“我的 → 检查更新”手动检查；确认下载后先校验完整安装包，再询问是否更新并重启。设置、收藏、登录态和壁纸库继续使用原数据目录，卸载也保留数据。
- **更新访问**：当前 Release 仓库公开，安装版无需配置 token 即可匿名检查并下载更新；仅当更新源是私有镜像或 Fork 时，才需要在“我的 → 更新源设置”填入对该仓库有 `Contents: Read-only` 权限的可选 token，令牌绑定当前 Windows 用户加密保存。安装包不包含任何开发者令牌。
- **发布**：推送到远端 `main` 触发 GitHub Actions 构建和发布；本地 commit 不触发。构建、版本规则、依赖和首次发布步骤见 [发布说明](docs/releasing.md)。

- **运行**：双击 `run.bat`（首次运行会自动安装依赖，用 `pythonw` 无控制台启动）。
- **动态转静态（自带转换组件）**：安装包内置 LGPL 构建的 `ffmpeg.exe` 与 `ffprobe.exe`（安装目录 `_internal\tools\ffmpeg\bin`），不需要用户另行安装 FFmpeg；源码运行把两个文件放到仓库 `tools\ffmpeg\bin` 即可。程序按“自带组件 → 系统 PATH → WinGet Gyan.FFmpeg”顺序查找；自带组件缺失、预览低于 1280×720 或解码不可验证时会明确拒绝转换，不会改用模糊缩略图。
- **安装**：双击 `install.bat` → 安装依赖、创建开始菜单/桌面快捷方式、开启开机自启。
- **卸载**：双击 `uninstall.bat` → 移除快捷方式与开机自启（数据目录保留）。

程序数据存放在 `%LOCALAPPDATA%\NativeWallpaperManager`；动态转换缓存位于其中的 `dynamic_frame_cache` 目录。

## 产品化特性

- **系统托盘**：关闭窗口即最小化到任务栏右下角托盘，双击托盘图标或右键"显示桌面画廊"恢复；右键"退出"才真正退出。
- **开机自启**："我的"页可一键开启/关闭随系统启动（写入 `HKCU\...\Run`，指向 `pythonw`，无控制台窗口）。
- **单实例**：重复启动只提示"已在运行"，不会开多个窗口。
- **登录态持久化**：微信扫码会话用 Windows DPAPI 加密保存，重启自动恢复登录。
- **图标**：`app/icon.ico` 用于快捷方式与托盘。

## 第三方组件与许可

- **FFmpeg / FFprobe**：安装包内置 `BtbN/FFmpeg-Builds` 的 Windows x64 LGPL 构建（固定版本、构建时校验 SHA-256），只用于把可验证的动态预览解码成静态 JPEG。许可证文本随包放在 `_internal\tools\ffmpeg\LICENSE.txt`；FFmpeg 源码与许可证见 <https://ffmpeg.org/legal.html> 与 <https://github.com/BtbN/FFmpeg-Builds>。转换组件以独立进程调用，不与桌面画廊源码链接。
- **WebView2 Runtime**：微信扫码登录窗口依赖系统已安装的 Microsoft Edge WebView2 Runtime。
- **Python 运行时与依赖**：由 PyInstaller 冻结进 `_internal`，第三方 Python 包的许可证随各自包分发。

## 边界

不抓取元气桌面的客户端私有接口、不复用官方客户端存储的 Cookie 或会员令牌、不绕过扫码确认、TLS、设备绑定或会员权限。登录使用官方公开登录页（`newvip.ijinshan.com`）完成微信扫码，客户端只读取本次会话并用公开资源服务校验。为保持重启后登录态，会话令牌用 Windows DPAPI 加密后保存在本机用户目录（`session.enc`，绑定当前用户、不进入 Git/日志/文档、不可跨机迁移）；明文令牌只驻留内存。高清原图下载若仍由官方客户端限制，则以官方平台规则为准。

动态转静态只处理能在本机验证并解码为标准视频的资源，不读取播放器缓存，也不会创建 WorkerW/WebView 桌面层。最终产物只是本地 JPEG；声音、交互效果和动画不会保留。回退的预览视频若带平台水印或合成组件，转换结果也可能保留。

电脑主题正式资源可能是 ZIP 外层加 `CWP3` 壁纸主体，并携带元气私有 `.thm`/`.skin7` 组件；这些不是 Windows `.theme`，程序不会解包后注入、模拟或硬套兼容。正式画面只有在能还原并通过标准视频探测时才使用，否则自动回退标准预览视频；下载或应用前会用默认取消的警告明确列出会丢失的组件。

`scene` 主题的时间、天气或交互组件若已被平台烘焙进 `preview_video`，程序无法从合成画面精确恢复被遮挡的原始背景，也不会用猜测区域或生成式补画强行消除。Windows 11 原生 Widgets 只显示在 Widgets Board，并不是可固定到壁纸上的组件，因此桌面画廊只做风险提示与用户确认，不接入桌面覆盖层。

会员资源不会被伪装成“已同步”：联网目录只使用本客户端经资源服务验证的扫码会话，服务端不返回或不允许下载的内容不会用模拟数据补齐。

`app/catalog.py` 定义了认证、分类、分页、搜索、预览、静态原图下载、动态转换和电脑主题降级的数据源契约。静态、动态和电脑主题分别沿用各自首页推荐流与服务端导航；全局搜索合并静态及动态/主题官方搜索接口，会话不完整或服务端拒绝时会显式报错。

`app/yuanqi_auth.py` 固化 `navigate2Login`、`callbackOnLogin`、`getUserInfo` 和 `getDeviceInfo` 等官方 H5 原生桥契约，并按实机登录窗建模微信二维码（默认）、手机登录和 QQ 三个入口。手机流程细分为请求验证码、等待验证码、提交和等待原生回调；手机号、验证码与令牌均不进入状态对象或持久化配置。

QQ 入口会由官方统一会员宿主 `kvipgui.exe` 拉起独立的“QQ帐号安全登录”页，默认使用 QQ 手机版扫码，也提供腾讯页面内的密码登录。实机授权方显示为“金山毒霸”，因此本项目只建模委托授权状态，不接收 QQ 密码，也不会复用该产品身份。

QQ 授权完成后，外部安全登录窗和快速登录弹窗关闭，元气主窗口用账号头像替换“登录”按钮并显示“关注”分类。这些只作为宿主回流的可见证据，不能绕过原生桥回调、用户/设备信息读取和服务端会话校验。

“资源接入”页不显示本地拼凑的假分类。登录后按静态资源服务返回的导航浏览和搜索；未登录时仍可迁移本机已有静态缓存，会员原图权限始终以服务端结果为准。

官方客户端登录与 H5 原生桥的实机研究记录见 [`docs/yuanqi-auth-architecture.md`](docs/yuanqi-auth-architecture.md)。
