# 原生壁纸管理器

一个轻量 Python Windows 程序：导入或下载你已获授权的静态图片，用 Windows 原生 `SystemParametersInfoW` 设置桌面壁纸。

它不会创建桌面覆盖层、隐藏图标、接管右键菜单或播放动态壁纸。

## 功能

- 导入 BMP/JPG/JPEG/PNG，复制到本地资料库
- 图库式资源卡片、缩略图和大图预览；点选卡片即可查看与应用
- 同步元气桌面官网首页公开展示的 5 张精选图片（不需要登录）。每张卡片都标为“元气官网首页公开展示”，可在官网页面和 `app/native_wallpaper.py` 中核对原始 HTTPS 地址
- “官方资源”页直达元气自有完整壁纸站的静态、4K、风景、小清新、动漫、明星、美女、科幻、动物、游戏、体育、汽车等真实分类
- 可在独立客户端窗口中内嵌上述官方站，分类、搜索、分页、详情和预览均由官方页面实时渲染；不解析页面、不读取登录态
- 内嵌浏览不依赖元气桌面的安装目录或运行进程；卸载官方客户端后，公开实时图库仍可使用
- 收藏、过滤、应用与移出资料库
- 仅接受 HTTPS 静态图片直链的下载入口
- 打开元气官方完整壁纸站浏览真实分类；会员登录与高清原图下载仍由官方客户端完成
- 收藏壁纸按分钟自动轮换
- 生成 Windows 标准 `.theme` 文件，交给系统原生主题与图片幻灯片机制应用
- 提供 Windows 原生鼠标、颜色、声音、通知和锁屏设置入口；不注入桌面或任务栏

## 运行

首次运行先安装图库预览依赖：

```powershell
python -m pip install -r requirements.txt
```

然后双击 `run.bat`，或执行：

```powershell
python app/native_wallpaper.py
```

程序数据存放在 `%LOCALAPPDATA%\NativeWallpaperManager`。

## 边界

不抓取元气桌面的客户端私有接口、不复用登录 Cookie 或会员令牌、不绕过会员限制。官方完整壁纸站可公开浏览分类和详情，但高清原图下载仍会跳转官方客户端；目前没有可供第三方使用的会员资源 API 或 OAuth 接口。若平台发布正式接口，可在此基础上新增认证数据源适配器。

会员资源不会被伪装成“已同步”：在没有官方授权接口前，本程序只能显示官网下载页公开展示的资源，或处理你从官方渠道明确导出的静态图片/直链。

`app/catalog.py` 定义了认证、分类、分页、搜索、预览和原图下载的数据源契约。元气正式适配器在缺少官方 OAuth/API 配置时会显式拒绝返回数据，不会用模拟响应冒充接通。
