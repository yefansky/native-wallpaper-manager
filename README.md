# 原生壁纸管理器

一个轻量 Python Windows 程序：导入或下载你已获授权的静态图片，用 Windows 原生 `SystemParametersInfoW` 设置桌面壁纸。

它不会创建桌面覆盖层、隐藏图标、接管右键菜单或播放动态壁纸。

## 功能

- 导入 BMP/JPG/JPEG/PNG，复制到本地资料库
- 图库式资源卡片、缩略图和大图预览；点选卡片即可查看与应用
- 元气桌面式双层导航、大图三列网格和固定底部操作栏；静态资源分类直接读取 `cate_nav_v2`，按元气服务端返回的顺序显示，不在本地猜分类 ID
- 资源接入页提供“静态壁纸 / 动态转静态”切换；动态页按元气当前的“关注、精选、最新 + `live/cate_nav_v2` 服务端分类”排列
- 元气动态资源只读取公开标准 `preview_video`：避开首帧，从全片 5 个时间点解码原始分辨率画面，以清晰度、对比度和曝光质量择优生成 JPEG，再走现有 Windows 原生静态壁纸接口
- 顶栏全局搜索从任何主分区进入统一结果页；同时合并本地图库、元气静态搜索和元气动态搜索，不继承当前分类筛选
- 同步元气桌面官网首页公开展示的 5 张精选图片（不需要登录）。每张卡片都标为“元气官网首页公开展示”，可在官网页面和 `app/native_wallpaper.py` 中核对原始 HTTPS 地址
- “官方资源”页直达元气自有完整壁纸站的静态、4K、风景、小清新、动漫、明星、美女、科幻、动物、游戏、体育、汽车等真实分类
- “资源接入”页明确显示正式授权状态；官网网页套壳不能下载、收藏或原生应用，因此不再冒充客户端资源接入
- 真实微信扫码登录：内嵌官方公开登录页 `newvip.ijinshan.com/#/auth/3`，由你本人用微信扫码，客户端读取内存会话并经资源服务 `POST /v1/user/info` 校验（`ret==0` 才判定登录成功）；登录后可“联网浏览壁纸”访问公开壁纸资源
- 复刻官方 PC 宿主可公开验证的登录桥契约与状态机：原生登录回调后必须重新取得用户/设备信息并完成服务端校验
- 收藏、过滤、应用与移出资料库
- 一键扫描本机已有的元气静态壁纸缓存：验证图片、按内容去重并复制到本程序目录；复制后不依赖官方客户端
- 本地图库按每页 12 张分页，避免大量缩略图一次性加载导致窗口卡顿
- 仅接受 HTTPS 静态图片直链的下载入口
- 打开元气官方完整壁纸站浏览真实分类；会员登录与高清原图下载仍由官方客户端完成
- 收藏壁纸按分钟自动轮换
- 生成 Windows 标准 `.theme` 文件，交给系统原生主题与图片幻灯片机制应用
- 提供 Windows 原生鼠标、颜色、声音、通知和锁屏设置入口；不注入桌面或任务栏

## 运行与安装

- **运行**：双击 `run.bat`（首次运行会自动安装依赖，用 `pythonw` 无控制台启动）。
- **动态转静态依赖**：需要 `ffmpeg.exe` 与 `ffprobe.exe`。程序会查找 PATH 和 WinGet 的 Gyan.FFmpeg 安装目录；找不到或预览低于 1280×720 时会明确拒绝转换，不会改用模糊缩略图。
- **安装**：双击 `install.bat` → 安装依赖、创建开始菜单/桌面快捷方式、开启开机自启。
- **卸载**：双击 `uninstall.bat` → 移除快捷方式与开机自启（数据目录保留）。

程序数据存放在 `%LOCALAPPDATA%\NativeWallpaperManager`。

## 产品化特性

- **系统托盘**：关闭窗口即最小化到任务栏右下角托盘，双击托盘图标或右键"显示桌面画廊"恢复；右键"退出"才真正退出。
- **开机自启**："我的"页可一键开启/关闭随系统启动（写入 `HKCU\...\Run`，指向 `pythonw`，无控制台窗口）。
- **单实例**：重复启动只提示"已在运行"，不会开多个窗口。
- **登录态持久化**：微信扫码会话用 Windows DPAPI 加密保存，重启自动恢复登录。
- **图标**：`app/icon.ico` 用于快捷方式与托盘。

## 边界

不抓取元气桌面的客户端私有接口、不复用官方客户端存储的 Cookie 或会员令牌、不绕过扫码确认、TLS、设备绑定或会员权限。登录使用官方公开登录页（`newvip.ijinshan.com`）完成微信扫码，客户端只读取本次会话并用公开资源服务校验。为保持重启后登录态，会话令牌用 Windows DPAPI 加密后保存在本机用户目录（`session.enc`，绑定当前用户、不进入 Git/日志/文档、不可跨机迁移）；明文令牌只驻留内存。高清原图下载若仍由官方客户端限制，则以官方平台规则为准。

动态转静态不会读取元气的完整 `video`、CWP 容器、加密资源或播放器缓存，也不会创建 WorkerW/WebView 桌面层。最终产物只是本地 JPEG；声音、交互效果和动画不会保留。预览视频本身若带平台水印，转换结果也可能保留该水印。

会员资源不会被伪装成“已同步”：联网目录只使用本客户端经资源服务验证的扫码会话，服务端不返回或不允许下载的内容不会用模拟数据补齐。

`app/catalog.py` 定义了认证、分类、分页、搜索、预览、静态原图下载和动态预览转换的数据源契约。静态与动态精选分别沿用各自首页推荐流，分类使用各自服务端导航与热门排序，全局搜索合并两类官方搜索接口；会话不完整或服务端拒绝时会显式报错。

`app/yuanqi_auth.py` 固化 `navigate2Login`、`callbackOnLogin`、`getUserInfo` 和 `getDeviceInfo` 等官方 H5 原生桥契约，并按实机登录窗建模微信二维码（默认）、手机登录和 QQ 三个入口。手机流程细分为请求验证码、等待验证码、提交和等待原生回调；手机号、验证码与令牌均不进入状态对象或持久化配置。

QQ 入口会由官方统一会员宿主 `kvipgui.exe` 拉起独立的“QQ帐号安全登录”页，默认使用 QQ 手机版扫码，也提供腾讯页面内的密码登录。实机授权方显示为“金山毒霸”，因此本项目只建模委托授权状态，不接收 QQ 密码，也不会复用该产品身份。

QQ 授权完成后，外部安全登录窗和快速登录弹窗关闭，元气主窗口用账号头像替换“登录”按钮并显示“关注”分类。这些只作为宿主回流的可见证据，不能绕过原生桥回调、用户/设备信息读取和服务端会话校验。

“资源接入”页不显示本地拼凑的假分类。登录后按静态资源服务返回的导航浏览和搜索；未登录时仍可迁移本机已有静态缓存，会员原图权限始终以服务端结果为准。

官方客户端登录与 H5 原生桥的实机研究记录见 [`docs/yuanqi-auth-architecture.md`](docs/yuanqi-auth-architecture.md)。
